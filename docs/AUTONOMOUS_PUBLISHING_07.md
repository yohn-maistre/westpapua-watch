# Autonomous publishing · Freeze 07

Current and existing Issue records run without routine human approval.

Pipeline: source discovery → extraction → Story Packet + relevance classification → embedding/clustering → synthesis writer → evidence critic → at most one revision → publish or silent hold.

The critic audits support, attribution, cluster coherence, syndication, headline certainty, and West Papua relevance. It does not require two sources: a single local report can publish when material claims remain explicitly attributed. Failed drafts are held rather than notifying campaign staff.

Existing Issue overviews remain curated. Published Developments and Issue deltas supply live updates/status/timeline. New persistent Issue creation remains conservative and based on the existing issue map for now.
